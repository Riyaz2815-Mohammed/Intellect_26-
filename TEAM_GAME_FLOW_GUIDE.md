# 🎮 CODECRYPT - Game Flow Guide for Teams

## 📱 How to Play

### **Step 1: Login**
1. Go to: **https://intellect26-codecrypt.vercel.app/**
2. Enter your **Team Name** and **Login Code** (from email)
3. Click **LOGIN**

## 🔄 Complete Game Flow

### **1️⃣ Start Your First Round**

**On Lobby Screen:**
- See your unique round sequence (highlighted first badge)
- Click **🚀 START MISSION**
- You'll be taken to your **first round**

---

### **2️⃣ Complete the Challenge**

**Each round has different challenges:**

| Round | Name | Type | What You Do |
|-------|------|------|-------------|
| **Round 1** | SQL Basics | Drag & Drop | Arrange SQL keywords to form queries |
| **Round 2** | Physical Access | Code Entry | Enter the physical code from location |
| **Round 3** | Memory Analysis | Flash Cards | Memorize data shown for 30 seconds |
| **Round 4** | Advanced SQL | Multi-Phase | Match queries, fix errors, enter code |

**Solve the challenge → Submit answer → Earn points!**

---

### **3️⃣ Get Your Next Code**

**After completing a round, the system will display a location:**

#### **For Most Rounds (1, 2, 4):**
1. 📍 **Physical Location Displayed** on screen
2. One team member **goes to that location**
3. **Organizer gives you the code** for your next round
4. Return to your team
5. **Enter the code** in the system
6. Next round unlocks!

#### **🎁 Special: After Round 3 (Memory/Flash)**
- **Email sent automatically** with your next code! ✉️
- **No need to visit a location** - this is your **ADVANTAGE** for completing the hardest round!
- Check your team email
- Enter the code
- Next round unlocks!

---

### **4️⃣ Move to Next Round**

1. You'll automatically return to **Lobby Screen**
2. Your sequence will show which round is **next** (highlighted)
3. Click **🚀 START MISSION** again
4. Complete the new challenge

**Repeat until all 4 rounds are done!**

---

### **5️⃣ Finish & See Results**

After completing all 4 rounds:
- 🎉 **Completion Screen** appears automatically
- See your **final score** and **position**
- View the **leaderboard** with all teams
- Celebrate! 🏆

---

## ⚡ Quick Tips

1. **Check Your Sequence:** Always look at the Lobby to know which round is next
2. **Physical Locations:** After most rounds, one member goes to get the code
3. **Round 3 Advantage:** After completing Round 3, check email for next code!
4. **Work Together:** All 3 team members can discuss and solve challenges
5. **Time Bonus:** Faster completion = more points!
6. **Ask Organizers:** If you're unsure where to go, ask the event organizers

## 🎮 Round Details

### **Round 1: SQL Basics (5 Questions)**
- Drag and drop SQL keywords
- Form correct queries
- 5 stages, each worth points

### **Round 2: Physical Access (1 Code Entry)**
- Enter the physical code you received
- Format: `CRPT-XXXX`
- One attempt to get it right

### **Round 3: Memory Analysis (5 Questions)** 🔥 **HARDEST**
- Data flashes for **30 seconds**
- Memorize and answer questions
- Mix of tables, queries, and logic
- **Reward:** Email code for next round!

### **Round 4: Advanced SQL (3 Phases)**
- **Phase 1:** Match queries to outputs
- **Phase 2:** Fix broken SQL queries
- **Phase 3:** Enter code (from physical location)

## ❓ FAQ

**Q: What if I don't receive the email code after Round 3?**
A: Check spam folder. If still missing, ask organizers - they have all codes in the Admin Panel.

**Q: Can we skip a round?**
A: No! You must complete rounds in your assigned sequence.

**Q: What if we enter the wrong code?**
A: You can retry. Points may be deducted for wrong attempts.

**Q: How do we know our rank?**
A: Click **LEADERBOARD** button in the header to see live rankings.

**Q: What happens if we get stuck?**
A: Use hints (costs points) or ask organizers for help.

**Q: Why do we get an email after Round 3?**
A: Round 3 (Memory Analysis) is the hardest round. As a reward for completing it, you get the next code via email instead of visiting a physical location!
